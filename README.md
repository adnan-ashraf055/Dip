# Digital Image Processing using Python

## About the Project
This repository contains my Digital Image Processing (DIP) practical programs implemented using Python. It includes image creation, image manipulation, and basic image processing operations using OpenCV and NumPy.

## Objectives
- Understand fundamental digital image processing concepts.
- Create and manipulate digital images using Python.
- Perform basic image processing operations.
- Learn image arithmetic and bitwise operations.
- Visualize and analyze image processing results.

## Technologies Used
- Python
- OpenCV (`cv2`)
- NumPy
- Matplotlib

## Programs Included

### 1. Image Creation
Creating images using NumPy arrays and OpenCV.

### 2. Basic Image Processing
Loading, displaying, and manipulating images using Python libraries.

### 3. Bitwise Operations
Performing bitwise operations on images:
- AND
- OR
- Other logical operations as implemented in the programs

### 4. Image Visualization
Displaying and saving processed images for analysis.

*More programs will be added as I continue learning Digital Image Processing.*

## Installation

Install the required libraries:

```bash
pip install opencv-python numpy matplotlib
```

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install the required libraries.
4. Run the desired Python program.

Example:

```bash
python fourth.py
```

Replace `fourth.py` with the name of the program you want to execute.

## Repository Contents
- `program.py` — DIP practical program.
- `third.py` — DIP practical program.
- `fourth.py` — Image creation and bitwise operations.
- Image files — Sample images and processing outputs used for practice.
